# Zymovo Static Site

Minimal premium synthetic biology laboratory showcase site for `Zymovo.com`.

## Pages
- Home
- Research
- Platform
- About
- Contact

## Stack
- Plain HTML
- Plain CSS
- Small vanilla JavaScript for nav state and mobile menu

## Design Notes
- Dark biotech aesthetic with restrained gradients and glass panels
- Multi-page layout for a more established lab/brand presentation
- Language stays aspirational and polished without making hard scientific or clinical claims

## Deployment
This folder is ready to deploy directly as a static site on Cloudflare Pages or any static host.
